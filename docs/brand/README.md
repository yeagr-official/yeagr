# Yeagr Brand Assets

This folder stores source brand handoff material for future Yeagr design work.

- `Yeagr Travel Brand Vision.zip` is the original handoff archive.
- `design_handoff_yeagr_rebrand/` is the extracted archive for easy review in Git.
- `design_handoff_yeagr_rebrand/design-references/` contains HTML reference boards.
- `design_handoff_yeagr_rebrand/code/` contains the original handoff snippets used to implement the current visual system.

The live app code remains in `app/`, `components/`, and `tailwind.config.ts`.
